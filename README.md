# SHLASH — Landing Page

صفحة هبوط واحدة تعريفية لشركة **شلاش** (عرض فقط — بدون طلبية من الموقع).

## التشغيل

```bash
cd shlash-distribution
npm install
npm run dev
```

## أقسام الصفحة

1. فيديو هيدر مربوط بالسكرول  
2. مين شلاش؟  
3. المنتجات (عرض)  
4. مناطق التوزيع  
5. عن شلاش  
6. تواصل / واتساب / نموذج رسالة  

## البيانات

عدّل المحتوى من:

- `src/data/company.ts`
- `src/data/catalog.ts`
- `src/data/coverage.ts`
- `src/data/contact.ts`
